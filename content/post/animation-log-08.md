### Stick figure animation

In this animation practice, I experimented with using the NLA (Non-Linear Animation) editor to extend a simple animation I had created. Additionally, I learned how to use the graph editor to clean up and smooth out the animation. This practice was highly educational, and I gained significant insights into the animation process. In the future, I plan to use the action editor and the pose mode together with the NLA editor to speed up my animation workflow.

What I learned:

- How to utilize the NLA editor to extend and manage animations.
- Techniques for using the graph editor to clean up and smooth out animations.
- The importance of leveraging different tools within the animation software to optimize the workflow.

Problems Encountered:

- Initial challenges in understanding the NLA editor's functionality.
- Difficulty in seamlessly integrating the graph editor with the overall animation process.
- Time-consuming process due to the learning curve associated with new tools.

Overall, this practice has enriched my understanding of the NLA editor and the graph editor, and their potential to streamline the animation process. I am excited to continue exploring these tools and incorporating them into my workflow to create more complex and efficient animations.
